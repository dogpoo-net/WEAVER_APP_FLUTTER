# 방문한 전체 보기 탭 재사용 실험

변경 전 기준 커밋: `7bea06b1e631ac8123428554c263a3721c9e1e28`.
이 기능은 별도 커밋으로 적용한다. 되돌릴 때 해당 기능 커밋을 `git revert`하면
앞선 검색 페이지네이션 등 다른 변경은 유지된다. 배포된 웹을 되돌리는 경우에는
되돌림 커밋으로 웹을 다시 빌드하고 배포해야 한다.

- 처음 방문할 때 생성한다. 방문하지 않은 탭은 생성하지 않는다.
- 데스크탑/태블릿은 방문한 탭을 보관한다. 너비/높이 중 짧은 쪽이 600 미만인
  화면은 현재 탭을 포함하여 최근 방문한 3개만 보관한다.
- 탭 설정에서 숨긴 화면과 워크스페이스가 바뀐 뒤의 화면은 폐기한다.
- 비활성 화면은 Offstage, TickerMode, ExcludeFocus, HeroMode로 표시/애니메이션/
  포커스를 제어한다. 탭마다 스크롤 컨트롤러 공유를 차단한다.
- 공용 데이터 동기화는 유지한다. 숨겨진 컬렉션의 요소/필터 갱신과 댓글 표시
  재구성은 건너뛰고, 다시 활성화될 때 현재 자료로 그린다.
- 숨겨진 캔버스는 키보드 선택 처리와 실시간 배치 적용을 중단한다.
  떠날 때 로컬 배치를 저장하고 돌아올 때 원격 변경과 병합한다.
  이미 숨겨진 캔버스를 캐시에서 폐기할 때 오래된 배치를 다시 쓰지 않는다.

전체 화면을 미리 생성하거나 모든 계산을 캐시하지는 않는다. 최초 진입 비용은
남고, 활성화 시 변경된 데이터의 필터/배치 계산도 남는다. 진행 중인 네트워크
작업 완료, 환경(테마/창 크기) 변경에 따른 Flutter 내부 재구성까지 모두 멈추는
구조는 아니다. 실제 기기의 FPS 개선 여부는 별도로 비교해야 한다.

회귀 검증: 탭 재방문 State 동일성, 검색 페이지 및 스크롤 유지, 복귀 시 새 자료,
모바일 3개 제한, 비활성 댓글 갱신 억제, 캔버스 배치/자동 저장/읽기 전용,
기존 검색/조회 최적화 테스트.
