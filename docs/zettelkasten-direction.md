# WEAVER의 제텔카스텐 방향

현재 구현 기준: 2026-11-05. 아래 전망은 시장 조사 결과가 아닌 제품 가설이다.

## 현재 강점과 부족한 점

빠른 기록, 독립된 생각, 양방향 연결, 해시태그, 메모상자, 프로젝트에서 참고하며 쓰는 흐름은 제텔카스텐의 토대가 된다. 그래프 자체보다 자기 말로 쓴 생각을 다시 읽고 연결하여 새로운 글을 만드는 경험이 핵심이다. 상자와 태그에 넣는 것만으로 의미 있는 연결이 생기지는 않는다.

가장 부족한 것은 연결 이유, 출처, 다시 읽기 흐름이다. 연결의 수보다 나중에 왜 연결했는지 이해할 수 있는지가 중요하다. 모든 메모를 엄격히 한 문장으로 제한하거나 기록할 때 분류를 강제할 필요는 없다.

## 이번에 추가한 작은 기능

- 페이지와 메모상자에서 생각 본문·해시태그 검색.
- '연결 없음' 필터: 다른 생각과의 연결이 없는 메모를 다시 검토한다. 상자 밖 연결도 이미 있는 연결로 인정한다. 태그만 붙은 생각은 여전히 검토 대상이다.

필터는 데이터나 연결을 삭제하지 않는다. 연결 없는 생각이 반드시 잘못된 메모라는 뜻은 아니다.

## 우선순위

1. 데이터 신뢰: 사용자 통제 가능한 백업·복원, Markdown/JSON 내보내기, 삭제 실행 취소, 이후 동기화. 현재 NAS 연동은 구현된 것으로 간주하지 않는다.
2. 연결의 맥락: 연결마다 '왜 연결했는가' 한 줄, 선택적으로 보충·반례·질문 같은 관계 종류. 출처 URL·책·페이지와 자신의 생각을 구분.
3. 재발견: 오래 읽지 않은 생각 몇 개를 보여주는 검토 흐름, 검토 뒤 연결·수정·나중에 보기. 연결 수를 늘리도록 강요하지 않는다.
4. 집필: 생각을 프로젝트 개요에 놓고 순서를 정한 뒤 글로 발전시키며 원본으로 돌아갈 수 있는 출처 링크 유지.

## UX 개선

- 사용자 용어는 '생각'으로 통일하고 '원소', '메타데이터'는 내부 개념으로 둔다.
- 기록 → 다시 보기 → 연결 → 글쓰기의 네 동작을 중심으로 메뉴를 정리한다.
- 그래프는 전체 지도와 선택한 생각의 주변 지도 두 수준으로 제공한다. 수가 많을 때 모든 선을 항상 강조하지 않는다.
- 태그 선은 태그 색, 상자 영역은 상자 색으로 표현하고 색 외에 이름과 선의 형태로도 관계를 구별한다.
- 모바일은 한 번 눌러 내용·연결·수정 동작을 보여준다. 더블클릭과 드래그만으로 기능을 숨기지 않는다.
- 배치 저장과 자동 정렬을 구분하고, 사용자가 옮긴 위치를 존중한다. 페이지·메모상자별 배치와 화면 이동·확대 배율을 브라우저에 자동 저장하고 복원한다.
- 새 사용자에게 작은 예시 세트로 생각 두 개를 연결하고 글에 사용하는 경험을 제공한다.

## 제품 방향과 수요 가설

'한국어로 빠르게 기록한 생각을 연결하고 실제 글로 발전시키는 작업 공간'에 집중한다. 시각화는 탐색과 집필을 돕는 도구다.

작가·블로거·독서 기록 사용자·개인 연구자에게 수요 가능성이 있다. 다만 Obsidian, Logseq, Notion 등에서 이전해야 할 이유는 그래프 하나로 충분하지 않다. 한글 입력의 안정성, 낮은 학습 비용, 모바일 기록의 편리함, 데이터 이동성이 차별화 후보이다. 문헌 관리가 중요한 연구자는 출처와 인용 기능이 갖춰져야 주요 대상이 된다.

10~20명의 목표 사용자가 2주 동안 자신의 메모로 사용하도록 검증한다. 일주일 후 재방문, 과거 생각을 다시 연 비율, 연결한 생각을 글에서 사용한 사례, 백업·동기화의 필요와 지불 의사를 확인한다. 그래프를 오래 보는 시간이나 연결 개수만으로 성공을 판단하지 않는다.
