# 음성 녹음 및 AI 텍스트 변환 (2026-11-18 갱신)

## 현재 정책

- 비회원/Free: 최대 1분 녹음 및 첨부. AI 변환은 제공하지 않는다.
- Standard/Pro 구독 계정: 최대 1시간 녹음, 녹음 전체 AI 변환.
- 앞 10초 맛보기 및 잘라 보내기 정책은 폐기했다.
- 변환 권한은 요청자 본인의 유효한 계정 구독으로 판단한다. 초대받은 유료
  워크스페이스에 참여했다는 이유만으로 Free 계정의 AI 변환을 허용하지 않는다.
- 워크스페이스 접근/쓰기 권한과 계정 구독을 서버에서 함께 검사한다.

## 구현

기본 Groq `whisper-large-v3-turbo`. 백오피스에서 Groq V3 또는 OpenAI
`gpt-4o-mini-transcribe`로 변경할 수 있다. API 키는 서버 api.env에만 보관한다.
설정 API에는 키 값 대신 설정 여부만 반환한다.

녹음 모달이 audio/policy로 권한을 조회한다. 녹음 종료 후 허용된 계정이면
자동 변환하며, 실패 시 다시 시도하거나 원본 녹음만 첨부할 수 있다.
텍스트는 VoiceAttachment.transcript에 원본 음성과 함께 저장되고 기존
워크스페이스 저장/동기화에 포함된다. 생각 상세에서 펼쳐 읽고 검색 탭에서 검색한다.

AAC/Opus 압축 녹음을 우선 사용한다. 압축 인코더가 없는 기기는 기존 PCM
녹음으로 대체하며 이 경우 메모리 폭증을 막기 위해 최대 1분으로 제한한다.
기존 WAV 녹음도 계속 재생 가능하다. 녹음 종료 시 32MiB 한도를 검사한다.

서버는 동시 변환 2개, 기존 계정 요청 제한, 실제 디코딩된 길이 최대 1시간을
검사한다. ffmpeg/ffprobe는 길이 검증과 MP3 표준화 용도다. WebM 컨테이너에
길이가 없어도 변환 후 실제 길이를 측정한다. 변환용 임시 파일은 finally에서 삭제한다.
프런트엔드 요청 제한은 변환에만 5분이며 일반 API 제한은 바꾸지 않는다.

DOGPOO 도구 경로: /home/ocaptain/api/audio-tools/{ffmpeg,ffprobe}.
WEAVER_FFMPEG/WEAVER_FFPROBE 환경변수로 교체 가능하다.
도구 배포 출처: https://johnvansickle.com/ffmpeg/ (7.0.2 static amd64).

## Workers 이전

일반 Workers에서 OS ffmpeg 프로세스를 실행할 수 없다. 앱은 공통
`audio/policy`, `audio/transcribe` API만 사용하므로 인증/구독 검사와 제공자 요청은
Workers로 옮기고, 형식 정규화/길이 검증은 지원 형식을 제한하여 재구현하거나
별도 오디오 처리 서비스로 분리한다. 클라이언트가 보낸 길이만 신뢰하지 않는다.

## 검증 범위

서버 정책/모델 제한, 무료 요청 403, WAV 및 길이 없는 WebM 합성 음원의 전체
변환(제공자 mock), 녹음 권한/취소, 자동 변환 권한 분기, 원본 보존, transcript
직렬화와 검색을 테스트한다. 배포 전 서버 키로 합성 음원 Groq 요청 200을 확인했다.
실제 마이크 품질과 기기별 1시간 녹음은 실기기 테스트가 필요하다.

## 비동기 첨부 및 재요청

변환 중에도 원본 음성을 메모에 첨부한다. 녹음 모달이 닫혀도 진행 중인 작업은
계속되며, 이미 저장된 같은 워크스페이스의 같은 음성 ID에 결과를 반영하고 저장한다.
삭제/교체된 음성이나 다른 워크스페이스에는 늦은 응답을 적용하지 않는다.
브라우저 종료로 작업이 유실되거나 연결이 끊겼다면 저장된 원본 음성에서 다시
요청한다. 생각 상세의 텍스트 없는 음성에 변환 버튼을 제공하며, 요청 시 계정
구독을 다시 확인한다. 같은 음성에 대한 동시 재요청은 하나로 합친다.

본문 없이 음성만 저장한 생각에는 voiceTextPending 플래그를 보관한다.
텍스트가 생기면 첫 줄 '음성 추출 텍스트', 다음 줄부터 추출 본문으로 채운다.
사용자가 본문을 직접 수정하면 플래그를 해제한다. 상세 편집 화면이 열려 있으면
본문 교체를 미루고 닫힌 뒤 확인한다. Free는 AI 요청이 없으므로 기존 제목을
유지한다. 동일 본문의 다른 생각이 이미 존재하는 경우 기존 중복 방지 규칙을
존중하여 자동 본문 교체를 하지 않고 음성의 변환 결과를 보관한다.

재요청은 모달에서는 실패한 경우에만 표시한다. 생각 상세에서는 음성 재생/삭제를
한 줄에 두고, 변환 텍스트는 아래 전체 너비에 작은 펼치기 버튼으로 제공한다.
구분선은 1px, outlineVariant 45% 색상이다.
