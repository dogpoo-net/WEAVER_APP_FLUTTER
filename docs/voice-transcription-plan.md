# 음성 녹음·텍스트 변환 구현 계획

작성: 2026-11-17 (한국 시간). 사용자와 합의한 정책 및 다음 구현을 위한 검토 자료.
**계획 문서이며, 아래 기능이 구현되었음을 의미하지 않는다.**

## 확정된 정책

| 구분 | 무료 | 구독 |
| --- | --- | --- |
| 1회 최대 녹음 길이 | 1분 | 1시간 |
| 텍스트 변환 범위 | 녹음 시작부터 앞 10초만 | 녹음 전체 |
| 음성 보관 | 최대 1분 원본 | 최대 1시간 원본 |

- 대상 플랫폼: iOS, macOS, Android, Windows, 웹브라우저.
- 플랫폼 간 음성 인식 품질의 일관성과 낮은 비용을 중요하게 고려한다.
- 운영 백엔드는 Cloudflare Workers 기반 서버리스로 계획한다. 현재 DOGPOO 테스트 서버와 구분한다.
- 이번 요청은 자료 정리이며, 음성 변환 구현·서비스 가입·과금 설정은 진행하지 않는다.

## 권장 방향 — 아직 구현 또는 공급자 확정 아님

각 플랫폼은 녹음을 담당하고, 공통 백엔드가 같은 외부 STT(음성 인식) 서비스로 전사를 요청한다.
OS·브라우저 기본 음성 인식은 엔진, 언어, 오프라인 지원 등이 달라 동일한 품질을 보장하기 어렵다.
클라이언트 API를 호출하더라도 실제로는 외부 서버에서 인식할 수 있다.
큰 모델을 웹에 직접 포함하는 방식은 다운로드·메모리·배터리·프레임 성능 부담 때문에 우선 추천하지 않는다.
같은 외부 모델을 사용해도 마이크·소음·녹음 형식에 따른 차이는 남는다.

권장 비동기 흐름:

1. 녹음 원본 업로드 및 저장(R2 후보).
2. 백엔드에서 사용자 권한·구독 상태·녹음 길이·변환 한도 검사.
3. 무료는 실제 음성 앞 10초만 추출. 10초 미만이면 존재하는 구간만 처리.
4. Queue에 작업 등록 후 Worker가 STT API 호출.
5. 전사 결과와 작업 상태 저장, 클라이언트에 완료 반영.

사용자는 업로드 후 다른 작업을 계속할 수 있게 하고, 처리 중에는 ‘텍스트로 변환 중…’을 표시한다.
기존 메모 본문을 자동으로 덮어쓰지 않고 전사 결과를 별도로 보관하는 방향을 권장한다.
실패해도 원본과 메모를 보존하고 재시도할 수 있어야 한다.
API 키는 클라이언트가 아닌 서버의 비밀 설정에서 관리한다.

## 무료 10초 제한과 서버리스 구현 주의점

- 전체 음성을 STT에 보낸 뒤 결과만 10초 분량으로 자르면 비용 제한이 되지 않는다.
- 반드시 전송하는 음성 자체를 제한한다. 클라이언트가 보내는 길이·플랜 정보를 그대로 신뢰하지 않는다.
- 압축 음성은 바이트 앞부분을 자르는 것으로 정확한 10초 파일을 만들 수 없다.
- 일반 서버의 FFmpeg 프로세스 실행 방식을 Workers에 그대로 적용할 수 없다.
- 추출 방식은 미정: 클라이언트의 독립적인 10초 미리보기 파일 생성과 서버 검증,
  적합한 서버리스 미디어 처리 서비스, 별도 변환 실행 환경 등을 비교해야 한다.
- Workers 실행 한도·메모리·지원 코덱·각 STT의 파일 크기/요청 제한은 도입 시 확인한다.
- R2에 저장했다고 공급자가 자동으로 읽는 것은 아니다. 공급자의 업로드/URL 지원에 맞춰 전달한다.

## 장시간 녹음과 비용 통제 — 후속 결정 필요

- 1시간 녹음은 중단·백그라운드 전환·네트워크 오류를 고려한 분할 저장/업로드를 권장한다.
- 분할 전사 시 시간 순서, 경계 문장 중복·누락, 재시도 및 최소 과금 시간까지 고려한다.
- 1회 최대 길이와 월간 총 변환 한도는 별개다. **무료·구독의 월간 한도는 아직 미정이다.**
- 자동 변환 시점, 재변환 허용 횟수, 동시 작업 수, 초과 과금 여부도 미정이다.
- 중복 요청/Queue 재전달/재시도로 같은 녹음이 반복 과금되지 않도록 작업 식별자와 중복 방지가 필요하다.
- 무료 사용자가 구독 후 기존 음성을 전체 변환하는 기능은 제안 단계다. 원본 보유·권한·한도 검사가 필요하다.
- 원본 저장·다운로드 트래픽·Queue·추출 처리 비용은 전사 비용과 별도로 산정한다.
- 외부 음성 전송, 공급자의 보관 정책과 처리 지역을 확인하고 개인정보처리방침에 반영한다.

## 구현 전 검증과 미결정 항목

1. 실제 Workers 경유로 동일한 10초·1분·1시간 파일을 후보 서비스에 보내 품질과 비용 측정.
2. 업로드 시간·Queue 대기·전사 시간·최종 반영 시간을 나눠 측정하고 평균 및 느린 요청(p95) 확인.
3. 한국어·영어 혼용, 이름/전문용어, 소음, 무음, 녹음 중단 사례로 정확도·허위 전사 확인.
4. 다섯 플랫폼의 코덱, 녹음 권한, 백그라운드 동작, 장시간 복구 검증.
5. 무료 10초 추출 방식과 서버 검증 방식 확정.
6. 공급자/모델, 월간 한도, 초과 정책, 전사 결과 UI, 구독 후 과거 녹음 재변환 정책 확정.
7. 플랜 변경·원본 교체·삭제 중 진행 중인 작업의 처리 및 접근 권한 검증.

화면 안내 제안: 무료 녹음 전에 ‘최대 1분 녹음할 수 있으며, 앞 10초만 텍스트로 변환됩니다.’ 표시.
