# WEAVER

제텔카스텐 방식의 노트박스를 만드는 Flutter 프로젝트입니다.

## 개발 시작

Flutter stable SDK를 준비하고 다음 명령을 실행합니다. 초기 환경에서 검증한 SDK 커밋은 `c197ca5199e9ee5661e865596c9c07294dfab51c`입니다.

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d chrome
```

Android 실행에는 Android SDK와 기기 또는 에뮬레이터가 필요합니다. iOS 빌드는 macOS와 Xcode가 필요합니다.

## Codex에서 이어서 작업

GitHub의 이 저장소를 선택하고 최신 커밋을 가져오세요. 클라우드 환경 스냅샷과 Git 커밋은 별개입니다. 소스와 작업 안내는 Git에 보관하고 SDK·캐시·빌드 결과는 커밋하지 않습니다.

현재 범위와 다음 작업은 [작업 인계](docs/HANDOFF.md)를 참고하세요.

## GitHub Pages

`.github/workflows/pages.yml`은 main 변경 또는 수동 실행 시 분석·테스트 후 웹 빌드를 GitHub Pages에 배포합니다. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 지정하세요.

기본 프로젝트 주소: https://dogpoo-net.github.io/WEAVER_APP_FLUTTER/

프로젝트 경로에 맞춰 `--base-href /WEAVER_APP_FLUTTER/`로 빌드합니다. 별도 서버·SSH 인증은 필요 없습니다. 실제 공개 여부는 Actions 배포 성공 후 확인하세요. 저장한 원소·문단·프로젝트는 같은 브라우저에서 새로고침 후 복원됩니다.


## 브라우저 데이터 보관

저장한 원소·문단·프로젝트·폴더는 현재 브라우저에 자동 보관되며 새로고침 후에도 유지됩니다. 서버 전송이나 JSON 파일 내보내기·가져오기는 제공하지 않습니다. 기존 저장 데이터 형식은 유지합니다. 저장 전 초안과 테마 선택은 복원 대상이 아닙니다.

데이터 초기화는 확인 후 메모리와 브라우저의 앱 저장본을 삭제합니다. 다른 브라우저·기기에는 공유되지 않으며 사이트 데이터를 지우면 기록도 삭제됩니다.

## 데스크톱 어시스트

넓은 화면에서는 커서 아래쪽의 배지 목록으로 후보를 표시합니다. Ctrl 단독 입력으로 글 입력/후보 선택 모드를 전환합니다. 선택 모드에서는 방향키로 배지의 실제 좌우·위아래 위치를 따라 이동하고 Enter 또는 Space로 삽입합니다. 한글 IME 조합 중에는 확정 키를 가로채지 않습니다. 한 글자는 접두어 검색, 두 글자 이상은 부분 검색하며 접두어 일치가 먼저 정렬됩니다. 모바일에서는 키보드 위에 전체 너비의 하단 배지 패널을 고정하고, 표시·숨김에 0.2초 슬라이드 애니메이션을 적용합니다. 후보가 많으면 패널 내부를 스크롤합니다. 문단 편집 영역은 기본 키보드 크기 조정을 사용하며, 키보드가 열려도 목록 맨 아래로 강제 이동하거나 어시스트 보정 여백을 추가하지 않습니다. 데스크톱 RTL에서는 오른쪽에 배치합니다.

## 해시태그

원소 작성 시 `작은 생각 #독서 #아이디어`처럼 입력합니다. 공백으로 시작하는 `#태그`는 본문과 분리해 보관하며, 중복 태그와 영문 대소문자를 정규화합니다. `C#`처럼 단어에 붙은 기호는 그대로 둡니다. 메뉴의 해시태그를 누르면 해당 원소와 그 원소를 사용하는 문단·프로젝트가 표시됩니다. 원소 없이 태그만 저장할 수는 없습니다. 태그도 브라우저 저장·초기화에 함께 포함됩니다.

### 원소와 프로젝트 정리
- 데스크톱 어시스트는 배지 목록입니다. Ctrl을 한 번 눌렀다 놓으면 후보 선택 모드, 다시 누르면 글 입력 모드입니다. 선택 모드에서는 방향키로 상하좌우 이동하고 Enter/Space로 삽입합니다. Escape도 입력 모드로 돌아갑니다.
- 메인 원소 배지를 길게 누르면 메타데이터가 열립니다. `원소 삭제`는 확인 후 글로벌 원소와 빠른 메모를 제거하며, 문단·프로젝트의 원문은 보존합니다.
- 메뉴의 `폴더 만들기`로 프로젝트 폴더를 만들고, 프로젝트 상단 `폴더 이동`으로 분류하거나 미분류로 되돌립니다. 빈 폴더와 소속 정보도 브라우저 저장에 포함됩니다.

데스크톱 메인 화면에서는 왼쪽 메뉴가 기본으로 표시됩니다. 메뉴 숨기기 → 아이콘으로 왼쪽 모달 열기 → 고정하기로 전환할 수 있습니다. 모바일은 모달 메뉴를 유지합니다.

기본 테마는 다크 모드입니다. 원소 메타데이터의 사용 문장을 누르면 해당 프로젝트 미리보기의 원소 위치로 이동합니다. 미리보기 원소는 Tab으로 포커스하고 Enter로 정보를 열 수 있으며 포커스 시 얇은 둥근 테두리가 표시됩니다. 폴더 생성은 메뉴 프로젝트 제목 옆 작은 아이콘입니다.

### 한글 폰트
Noto Sans KR 가변 폰트를 `assets/fonts`에 라이선스와 함께 포함했습니다. 앱 시작 전 FontLoader로 로딩하고 라이트·다크 테마에 적용합니다. 한글 입력 시 글자별 외부 대체 폰트 로딩을 줄이며, 최초 다운로드 용량은 약 10MB 증가합니다. 다른 언어·이모지의 대체 폰트 동작은 유지합니다.

메인 원소 배지를 클릭하면 메타데이터 모달이 열립니다. 모달의 여러 줄 입력창에서 내용과 #태그를 수정하고 저장할 수 있습니다. 원소 ID·생성일·색상은 유지되며 기존 문단/프로젝트 원문은 자동으로 바뀌지 않습니다. 빈 내용과 다른 원소와 동일한 내용은 저장할 수 없습니다.

메뉴의 프로젝트·해시태그는 각 섹션의 폴더로 드래그해 분류하고 `미분류`로 드래그해 꺼낼 수 있습니다. 모바일은 길게 누른 후 드래그합니다. 해시태그 폴더는 해시태그 제목 옆 생성 아이콘으로 만들며, 분류 정보도 브라우저 저장에 포함됩니다.
